저장소의 supabase-config.js 파일에 Supabase 주소(url)와 공개 키(anonKey)를 넣어 주세요.

  1. Supabase에서 프로젝트를 만듭니다.
  2. SQL Editor에 supabase_setup.sql 내용을 붙여 넣고 실행합니다. (관리자 이메일로 바꿔서)
  3. Authentication → Users → Add user 로 관리자 계정을 만듭니다.
  4. Project Settings → API 의 Project URL 과 anon public 키를 supabase-config.js 에 넣고 올립니다.
